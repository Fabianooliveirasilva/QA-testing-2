# AI-Assisted QA Prompts

Five reusable prompts for use with ChatGPT, Claude or any chat assistant. No API key or paid service is required:
copy the prompt, fill the `{{placeholders}}`, paste the answer into a draft and review it.

| Prompt | Use it to |
|--------|-----------|
| [test-case-generator.md](test-case-generator.md) | Generate structured test cases from a feature |
| [bug-report-assistant.md](bug-report-assistant.md) | Draft a bug report from raw notes |
| [test-coverage-analyzer.md](test-coverage-analyzer.md) | Find coverage gaps |
| [regression-test-advisor.md](regression-test-advisor.md) | Choose regression tests after a change |
| [test-result-analyzer.md](test-result-analyzer.md) | Triage Playwright failures |

Principles: AI output is a hypothesis; evidence and inference are labelled; results are never invented; a human approves everything.

See [../examples/](../examples/README.md) for each prompt applied to real project data.
